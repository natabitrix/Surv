## Столпы ARK (базовые системы)

1. **Собирательство / добыча** — ресурсы (дерево, камень, металл, волокно, солома, кремень, обсидиан, кристалл, нефть)
2. **Крафт** — энграммы, рецепты, тиры качества, blueprints
3. **Строительство** — снапы, стабильность, электрика, ирригация
4. **Инвентарь** — вес, стаки, прочность, ремонт, hotbar
5. **Прогрессия** — XP, уровни, энграммы, распределение статов
6. **Боевка** — ближний/дальний бой, зоны урона, броня, оружие
7. **Приручение существ** — knockout / passive, наркотики, кормление
8. **Использование прирученных** — riding, команды, инвентарь, mounted combat
9. **Экосистема** — хищники/жертвы, respawn по регионам, пищевая цепочка
10. **Броня** — сеты, защита, прочность, резисты
11. **Температура / погода** — гипер/гипотермия, биомы, дождь/снег/туман
12. **Респавн** — по кроватям/спальным мешкам, точки возрождения
13. **Статы** — влияние на геймплей (weight, melee, speed, crafting speed, fortitude)
14. **Биомы + ресурсы по регионам** — пляжи, джунгли, горы, пещеры, болота, снег
15. **Фермерство** — грядки, семена, урожай, удобрения
16. **Разведение** — спаривание, инкубация, imprinting, мутации
17. **Племена** — кланы, ранги, общие структуры/дино
18. **Боссы** — арены, призывы, лут
19. **Мультиплеер** — сервер-авторитарный, PvP/PvE
