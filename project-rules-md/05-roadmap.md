# 05. Roadmap

> Долгосрочный план по столпам ARK. Не путать с `04-todo-bugs.md` (там — конкретные баги/задачи).

## v0.1 — Закрыть базовый геймплей (сейчас)

- [x] **Базовый AI прирученных**: режимы Follow, Wander, Aggressive, Protect. Исправлен поиск целей через `GetComponentInParent`.
- [x] **Mounted Combat (Боевка верхом)**: игрок атакует существом (ЛКМ), свой урон и кулдаун.
- [x] **Архитектура существ**: `CreatureData` разбит на логические блоки, общие настройки вынесены в `CreatureGlobalConfig`.
- [x] **Атрибуция урона**: добавлен `CombatMember`, цвета цифр урона (Свой->Дикий = Зеленый, Дикий->Свой = Желтый, Дикий->Дикий = скрыто).
- [ ] **SettingsController** — единая система настроек (MainMenu + Pause, JSON).
- [ ] **Фикс-сессия** — собрать все баги из `04-todo-bugs.md`, починить.
- [ ] **UI заголовок чужого инвентаря** — `OwnerPlayerId` / имя в панели.
- [ ] **Разрушение сундука → сумка** — `ChestController.OnDestroy` → `LootBagManager`.
- [ ] **Проверить `Structure.Die`** — выброс содержимого в сумку.
